# Rock Paper Scissors Game

A classic Rock Paper Scissors game played in the browser console. Built with vanilla JavaScript as part of The Odin Project curriculum.

## 🎮 How to Play

1. Open `index.html` in your browser
2. Press `F12` to open Developer Console
3. Enter your choice when prompted: rock, paper, or scissors
4. Play 5 rounds against the computer
5. See who wins!

## 🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

## 🛠️ Built With

- HTML5S
- CSS3
- JavaScript (ES6)
